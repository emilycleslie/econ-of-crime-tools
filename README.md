# Econ of Crime Tools

Interactive, student-facing tools for economics of crime courses.

## Becker model explorer

The [Becker model explorer](https://emilycleslie.github.io/econ-of-crime-tools/becker-explorer/) is a hands-on companion to Becker (1968), designed for ECON 413R.

This public repository contains only materials intended for students. Course planning files, readings, administrative records, and other private teaching materials live elsewhere.
